# Análise de Sentimentos com Inteligência Artificial

Concluí mais uma etapa da minha jornada de aprendizado em Python e Inteligência Artificial durante a iFood Dev Week. Neste projeto, desenvolvi uma aplicação capaz de realizar análise de sentimentos em feedbacks educacionais utilizando a API da OpenAI.

O objetivo foi automatizar a interpretação de comentários de usuários, identificando percepções, opiniões e tendências presentes nos feedbacks. Durante o desenvolvimento, trabalhei conceitos importantes como manipulação de dados em Python, construção de prompts para modelos de linguagem, integração com APIs de IA e processamento de texto.

Além da implementação da análise de sentimentos, o projeto proporcionou uma compreensão prática sobre como a Inteligência Artificial pode transformar dados não estruturados em insights valiosos para a tomada de decisão, especialmente em contextos educacionais e de experiência do usuário.

Tecnologias utilizadas:

* Python
* OpenAI API
* Processamento de Linguagem Natural (NLP)
* Engenharia de Prompts

Este projeto reforçou meus conhecimentos em desenvolvimento Python e ampliou minha experiência com aplicações práticas de Inteligência Artificial, uma área que continua revolucionando a forma como analisamos e utilizamos dados.
